# Bundled fonts (the Windows app runs offline)

| Folder | Font | Source | Licence |
| --- | --- | --- | --- |
| `inter/` | Inter (UI text), weights 400/500/600/700, latin + latin-ext subsets, woff2 | npm `@fontsource/inter@5.3.0` (built from rsms/inter) | SIL OFL 1.1, `inter/OFL.txt` |
| `bowlby-one/` | Bowlby One (display face, OFL stand-in for "Lateral"), latin subset, woff2 | npm `@fontsource/bowlby-one@5.3.0` (built from google/fonts) | SIL OFL 1.1, `bowlby-one/OFL.txt` |

The files are unmodified. The `@font-face` rules are at the top of `static/app.css`.
